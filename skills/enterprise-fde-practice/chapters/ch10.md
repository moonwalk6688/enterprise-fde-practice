# Observe the work before designing the system

**来源**：Building an Enterprise FDE Practice，第10章；OCR第746—818行。

## 核心判断

先观察真实用户完成任务，再设计系统。

## 何时使用与怎么做

用于讨论Observe the work before designing the system相关的真实项目决策。跟踪普通案例和异常案例，识别数据、权限、流程、结果验收人。先写下当前证据、缺失信息、拥有决策权的人和下一次检验时间；把这一步视为本技能的应用推演，不冒充作者原话。
