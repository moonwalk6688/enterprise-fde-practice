# 决策速查

| 眼前问题 | 必要判断 | 留下的决定 |
|---|---|---|
| 新团队接太多请求 | 问题、权限、决策者、接收方是否齐 | 准入/搁置/转交 |
| 计划总工时看似够 | 稀缺技能、辅导、旧支持是否够 | 延后/缩范围/增容 |
| 试点效果达标 | 有用、技术、运行、采纳四项是否分别过 | go/hold/revise/stop |
| Agent 要执行写动作 | 谁授权确切资源与载荷，未知结果如何对账 | 允许范围或停止 |
| 客户已收到文档 | 接收方能否亲自恢复系统 | 移交验收或返工 |
| 项目显示节省工时 | 是释放容量、增量产出还是减支现金 | 收益归属与复核 |
| 打算扩张团队 | 合格需求、可兑现容量、维护尾巴 | 投资/缩小/伙伴 |

所有百分比写分子、分母、时间窗、排除项、数据源。所有管理结论按“观察→推断→建议→授权”表达；未知要明写，不能填零。
